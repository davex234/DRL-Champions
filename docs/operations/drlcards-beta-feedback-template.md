# DRLCards · Plantilla de feedback (beta cerrada)

Copia, rellena y envía al operador. Cuanto más concreto, antes se arregla.

```
Qué estabas intentando hacer:
  (p. ej. «abrir mi segundo Sobre Inicial desde la guía»)

Qué esperabas que pasara:

Qué ocurrió en realidad:
  (mensaje exacto si hubo uno; si la pantalla se quedó igual, dilo)

Captura:
  (adjunta la imagen; si hay un «Código: XXXXXX», cópialo)

Hora aproximada:
  (con zona horaria, p. ej. 2026-09-27 14:05 CEST)

Navegador y dispositivo:
  (p. ej. Chrome 131 · Windows 11 · 1440 px · «reducir movimiento» activado/desactivado)

¿Lo puedes repetir?  sí / no / a veces
```
